## 关于本项目

DK-FUCMP 是一个已被所有者归档的公开仓库。它的目录树里只有 GitHub 自带的启动模板所生成的脚手架文件：一份 Contributor Covenant 版的 `CODE_OF_CONDUCT.md`、一份 `SECURITY.md` 安全报告政策、议题与合并请求模板、CODEOWNERS，以及一份只监控 GitHub Actions 版本更新的 `.github/dependabot.yml`。`CHANGELOG.md` 在 `[Unreleased]` 下唯一的一条记录是 "Initial project structure."（初始项目结构）。

仓库里没有任何清单文件、没有入口点、也没有任何语言的源代码文件，因此没有什么可以安装、构建或运行的东西。

计划中的功能与已知问题，见 [open issues](https://github.com/anyingiit/DK-FUCMP/issues)。

## 开始使用

### 环境要求

- [Git](https://git-scm.com/)，用于克隆本仓库。
- （可选）[pre-commit](https://pre-commit.com/)，如果你想在提交前运行 `.pre-commit-config.yaml` 中声明的检查。

### 安装

```sh
git clone https://github.com/anyingiit/DK-FUCMP.git
cd DK-FUCMP
pre-commit install  # 可选 -- 仅当你打算在此仓库中提交更改时才需要
```

## 用法

本仓库中没有可运行的应用程序。目录树仅限于上面描述的脚手架内容：参见 [CONTRIBUTING.md](CONTRIBUTING.md) 了解原本设想的贡献方式，参见 [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE) 下的表单了解原本设想的缺陷报告与功能请求方式。

## 参与贡献

欢迎参与。[CONTRIBUTING.md](CONTRIBUTING.md) 说明如何提交 issue 或 pull request，[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) 说明对所有参与者的行为要求。

请不要在公开的 issue 或 pull request 中报告安全问题。[SECURITY.md](SECURITY.md) 说明了私下报告的方式。
