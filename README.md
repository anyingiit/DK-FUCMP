## About The Project

DK-FUCMP is a public repository that its owner has archived. Its tree holds only the scaffolding that GitHub's own starter templates produce: a Contributor Covenant `CODE_OF_CONDUCT.md`, a `SECURITY.md` reporting policy, issue and pull request templates, CODEOWNERS, and a `.github/dependabot.yml` that only watches GitHub Actions versions for updates. `CHANGELOG.md`'s only entry, under `[Unreleased]`, is "Initial project structure."

There is no manifest, no entry point, and no source file in any language anywhere in the tree, so there is nothing here to install, build, or run.

See the [open issues](https://github.com/anyingiit/DK-FUCMP/issues) for planned features and known issues.

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/), to clone the repository.
- (Optional) [pre-commit](https://pre-commit.com/), if you want to run the checks declared in `.pre-commit-config.yaml` before committing.

### Installation

```sh
git clone https://github.com/anyingiit/DK-FUCMP.git
cd DK-FUCMP
pre-commit install  # optional -- only needed if you plan to commit changes here
```

## Usage

There is no application in this repository to run. The tree is limited to the scaffolding described above: read [CONTRIBUTING.md](CONTRIBUTING.md) for how contributions were meant to be made, and the forms under [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE) for how bugs and feature requests were meant to be filed.

## Contributing

Contributions are welcome. Read [CONTRIBUTING.md](CONTRIBUTING.md) for how to open an issue or a pull request, and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the standards expected of everyone taking part.

Please do not report security issues in public issues or pull requests. [SECURITY.md](SECURITY.md) explains how to report them privately.
